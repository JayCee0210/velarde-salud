# UX móvil Android

- El panel usa una barra inferior contextual y conserva las capacidades por rol.
- El objetivo mínimo es 360 px sin desplazamiento horizontal.
- Acciones frecuentes usan controles táctiles de al menos 44 px.
- Se prefieren tarjetas y formularios cortos sobre tablas densas.
- Se muestran estados de carga, error y confirmación de guardado.
- No existe modo offline para expedientes médicos ni almacenamiento local clínico.
- La PWA es ligera y solo inicia en la web pública; no convierte datos clínicos en caché pública.
